# PB Radar — радар публічних робочих контактів для Windows

Локальна програма для пошуку **публічно опублікованих робочих телефонів** українських архітектурних, дизайнерських і будівельних організацій. Не пов'язана з Бітрікс24 або парсером новобудов.

## Нове у версії 0.4.3

- **Прозоре пояснення кількості результатів:** «додано 115 нових номерів» — це результат імпорту/сканування, а «Показано 5 із 429» — поточний вигляд таблиці з фільтрами. Під пошуком тепер окремий лічильник прихованих номерів із причинами: джерело (вимкнений Prozorro), тип організації (наприклад, «Тільки приватні»), статус («Лише нові») або текстовий пошук.
- **«Показати всю базу»:** скидає лише фільтри відображення номерів і текстовий пошук; не видаляє записи, не змінює статуси і не чіпає географію чи категорії подальшого збору. **«Розгорнути групи»** показує телефони всередині згрупованих організацій, повторне натискання згортає їх.
- **Три секції з вільною висотою:** перетягуй тонкі горизонтальні розділювачі між фільтрами категорій/областей, панеллю дій/стану та таблицею контактів. Розташування зберігається в наявній SQLite-базі й відновлюється при наступному запуску навіть на екрані іншого розміру.
- **↺ у правому верхньому куті:** одним натисканням повертає всі висоти секцій та ширини стовпців до стандартних значень. Контакти, обрані категорії, фільтри джерел та позначки менеджерів не скидаються. Залишився окремий швидкий спосіб «Скинути ширину» для самої таблиці.

## Нове у версії 0.4.2

- **Копіювання з таблиці:** подвійний клік на номері копіює повний телефон у буфер обміну; подвійний клік на стовпці «Сайт / посилання» копіює саме відображене посилання без відкриття браузера.
- **Контекстне меню правою кнопкою миші:** «Копіювати номер», «Копіювати посилання», «Копіювати комірку (Ctrl+C)» та «Відкрити посилання». Недоступні дії вимикаються, а згорнутий рядок «7 номерів» не копіюється як телефон. Для відкриття джерела можна скористатися меню або подвійним кліком по іншій частині рядка.
- **Ctrl+C:** клацни потрібну комірку та натисни Ctrl+C — скопіюється її видиме значення. Результат копіювання підтверджується в рядку стану. Не змінює дані контактів, сортування та статуси менеджера.

## Нове у версії 0.4.1

- **Згортання номерів за організацією:** замість семи окремих рядків одного підприємства відображається один рядок «7 номерів», який можна розкрити стрілкою або подвійним кліком. Номерів не видалено: кожен зберігає статус, джерело та доступний під рядком фірми. Якщо телефон лише один, показується звичайний рядок. CSV залишається по одному телефону в рядку, щоб менеджери могли працювати з кожним номером.
- **Групування за ЄДРПОУ:** з нових записів Prozorro зберігається офіційний ідентифікатор організації. Якщо в тієї самої юрособи відрізняються назви, філії або області, групуємо за однаковим ЄДРПОУ. Самої схожості назв недостатньо для об'єднання різних юридичних осіб. Для старих записів ЄДРПОУ з'явиться після повторного отримання інформації із джерела.
- **Фільтр типу організації:** «Без державних» (за замовчуванням), «Тільки приватні», «Державні», «Не визначено», «Усі». Для замовників Prozorro використовуємо офіційне поле `procuringEntity.kind`; для інших — явні ознаки назви (наприклад, «ТОВ», «ФОП», «Комунальне»). Це допоміжна класифікація, **не юридична перевірка власника**. «Без державних» включає невизначені організації; якщо потрібна лише очевидна приватна форма, обери «Тільки приватні».
- **Ручна перевірка власності:** виділи фірму або номер і зміни «Позначити вибрану» на «Приватна», «Державна / комунальна» чи «Не визначено». Рішення менеджера не перезаписується черговим пошуком; записи з однаковим ЄДРПОУ отримують спільне позначення.
- **Перемикач «Показувати Prozorro»:** можна миттєво приховати контакти цього джерела, не видаляючи їх з бази. Якщо той самий номер окремо знайдено в іншому джерелі, показується його незалежний запис. CSV-експорт поважає перемикач, власність, «Лише нові» й пошук.
- **Ширина стовпців:** перетягни межу заголовка таблиці мишею; програма запам'ятає ширину для наступного запуску. Кнопка «Скинути ширину» повертає стандартні розміри. Усі налаштування, тип організації, номери й статуси живуть у старому файлі `%LOCALAPPDATA%\PB-Radar\contacts.sqlite3`, без зайвих файлів. Оновлення не потребує завантаження OSM і не стирає історію менеджера.

## Що працювало у версії 0.4.0

- **Пошук у локальній базі за всіма полями:** над таблицею є рядок пошуку за назвою компанії, телефоном (у форматі `067…` або `+380…`), областю, категорією, посадою, активністю, статусом менеджера, сайтом, соцмережею та посиланням на джерело. Можна вводити кілька слів одночасно; показано число знайдених збігів. CSV-експорт враховує поточний пошук та перемикач «Лише нові».
- **Новий незалежний канал — публічний API Prozorro:** кнопка «Prozorro · контакти» шукає опубліковані робочі телефони закупівельників **без OSM та повторної індексації PBF**. Для будівельних, архітектурних, проєктних, монтажних та окремих дизайнерських категорій також перевіряються переможці закупівель за відповідними CPV-кодами. Усі результати мають посилання на офіційний тендер. Дані з державних установ теж можуть потрапляти у категорію «Відділи закупівель» — менеджер має оцінити їхню придатність для співпраці.
- **Поступове наповнення з Prozorro:** один запуск переглядає до 5000 публічних записів (до 300 детальних карток постачальників), потім зберігає позицію у тій самій локальній SQLite-базі. При наступному запуску можна продовжити старіші записи або почати з найновіших. Повторні телефони не створюють нових контактів; опрацьовані статуси зберігаються.
- **Чесний лічильник OSM:** десятки мільйонів — це *картографічні об'єкти* (будівлі, дороги, вузли), а не запити до реєстрів і не список підприємств. Під час нової індексації окремо показуються кандидати з безпосереднім телефоном і записи лише із сайтом. Оновлення 0.4.0 **не вимагає перебудови** вже готового OSM-індексу версії 3.
- **Фірмова іконка Windows — без фону:** ярлики робочого столу, меню «Пуск», встановлювач, лаунчер і вікно застосунку використовують лише надану червону конструкцію з реальною прозорістю. Також усунуто проблему, коли CustomTkinter через 200 мс замінював іконку головного вікна на свою бірюзову. Для зміни іконки вже встановленого лаунчера потрібно один раз повторно запустити `PB-Radar-Setup.exe` із релізу 0.3.3; OSM і контакти залишаться на місці.
- **Windows-інсталятор:** `PB-Radar-Setup.exe` встановлює лаунчер у `%LOCALAPPDATA%\Programs\PB Radar\`, створює ярлики меню «Пуск» і (за вибором) робочого столу. Інсталяція доступна без прав адміністратора. Один раз встановив — надалі оновлення застосунку завантажує сам лаунчер.
- **Постійне сховище:** архів OSM, індекс областей, база телефонів і статуси менеджера зберігаються окремо від лаунчера в `%LOCALAPPDATA%\PB-Radar\`. Повторне встановлення та видалення лаунчера їх не стирає. У лаунчері є кнопка «Відкрити папку даних / OSM».
- **Розширений OSM-радар:** аналіз усіх трьох типів об'єктів OSM — точок, контурів (ways) і відношень (relations). Для контурів область визначається за координатами вузлів, а для записів із адресою — за областю або назвою обласного центру. Для координат використовується тимчасовий індекс у пам'яті, без дублювання PBF на диску.
- **Більше професій і робочих контактів:** пошук за тегами `office`, `craft`, `company` і назвами українською, російською та англійською; враховуються компанії з назвою в `brand` або `operator`, а також деякі явно позначені неназвані офіси/майстерні. Розпізнаються `phone`, `contact:phone`, `mobile`, `contact:mobile`, `phone:2`, `telephone`, `website`, `url` та інші публічні поля. Посилання на Instagram/Facebook/LinkedIn/Telegram зберігаються окремо від офіційного сайту.
- **Без втрати потенційних компаній:** релевантні OSM-організації, у яких не вказано ані телефону, ані сайту, теж залишаються в локальному індексі для подальшого зіставлення з іншими відкритими джерелами. Поки вони не потрапляють у список телефонів, бо номера ще немає. У статистиці прогресу їх видно окремо.
- **Без випадкової межі у 1500 організацій і 120 сайтів:** радар обходить усіх кандидатів за фільтром, а перевірені сайти заносить у маленький локальний журнал. Сайти, що дали номери, повторно перевіряються приблизно через 7 днів, сайти без результатів — через добу. Пошук можна зупинити й продовжити пізніше, не перевіряючи ті ж сайти одразу знову. Пошук може тривати довго, якщо сайтів багато; обхід однопоточний і дотримується `robots.txt`.
- **Оновлювати PBF після встановлення 0.3.x не потрібно.** Існуючий архів України використовується повторно; локальний SQLite-індекс буде автоматично перебудовано, лише якщо змінився алгоритм індексації. База контактів і статуси менеджера не скидаються.
- **Прогрес індексації:** програма спочатку один раз швидко підраховує всі OSM-точки, лінії й відношення у PBF, а потім показує `перевірено / усього`, точний відсоток, приблизний час до завершення та окремі лічильники релевантних кандидатів і кандидатів із публічними контактами. Попередній підрахунок додає час до першої індексації, зате не видає оцінку за точне число. Результат зберігається в наявному файлі індексу.
- **Діагностика охоплення:** під час побудови індексу окремо враховуються об'єкти, що підпали під категорії, але не містять телефону чи сайту безпосередньо в OSM. Це пояснює, чому кількість придатних кандидатів може бути значно меншою за загальну кількість картографічних об'єктів.
- Фірмовий логотип **Polski Bramy** на прозорому фоні у верхній панелі (без білої картки) та компактний червоний знак у заголовку вікна; світлий напис читається на темній темі.
- **Резервне джерело OSM України:** якщо сервер Geofabrik повертає циклічний HTTP 308/302, програма автоматично перемикається на повний український PBF від [OSM France](https://download.openstreetmap.fr/extracts/europe/ukraine-latest.osm.pbf). Короткі коректні HTTPS-перенаправлення дозволені, нескінченні — зупиняються. Старий локальний файл при помилці не втрачається.
- Сучасний темний інтерфейс із чекбоксами категорій, областей і статусів, стрічкою прогресу та таблицею номерів.
- Виправлено **Exceeded 30 redirects**: стара адреса `ukraine-latest.osm.pbf` на Geofabrik зациклює HTTP 308. Програма визначає найновіший *датований* PBF за офіційним каталогом Geofabrik, завантажує його без переходів і має резервну перевірку датованих адрес. На помилковому посиланні збережений PBF не стирається.
- Вибір категорій і **всіх 27 адміністративних одиниць України**, включно з Києвом, АР Крим і Севастополем; можна обрати всі відразу.
- **Виправлена помилка geoBoundaries:** спрощені межі областей включені у збірку. Пошук за областями не залежить від доступності зовнішнього API.
- **Єдиний OSM-файл для всієї України** з Geofabrik і **локальний SQLite-індекс**. При першому завантаженні або заміні PBF індекс будується один раз; переключення областей надалі не потребує повторного читання всього PBF.
- Стан локальних OSM-даних у верхній частині: **Оновлений** (<24 год), **Готовий** (<7 днів), **Потребує оновлення** (старіший або відсутній). Це оцінка віку файлу на ПК, а не доказ наявності новішого дампу на сервері.
- При оновленні новий PBF та індекс спочатку записуються у тимчасові файли й лише після успішного завершення **замінюють попередні**. Копії за датами не накопичуються; залишаються один PBF, один індекс і база контактів.
- Пошук у **відкритому дампі OpenStreetMap України** (nodes/ways/relations; географія деяких relations без адреси все ще може бути невизначеною).
- Отримання телефонів безпосередньо з даних OSM та офіційних сайтів, які дозволяють автоматизоване читання (`robots.txt`), без штучного ліміту на кількість сайтів.
- Локальна SQLite-база в `%LOCALAPPDATA%\PB-Radar\contacts.sqlite3`.
- Дедуплікація за компанією/номером. Статуси опрацювання зберігаються при повторних пошуках і оновленнях програми.
- Одна згорнута група на організацію з розкриттям телефонів; кожен унікальний телефон має власну галочку **☐ / ☑** і статус. Статус зберігається, навіть якщо телефон повторно знайдено для іншої компанії.
- За замовчуванням відображаються **лише не опрацьовані** номери. Зніми цей фільтр, щоб переглянути позначки та історію; поверни номер у роботу, натиснувши на галочку повторно.
- Експорт у CSV з UTF-8 BOM для відкриття в Excel; імпорт CSV `name,category,region,phone,website`.
- Окремий лаунчер із перевіркою GitHub Releases, SHA-256-контролем пакета та версіями в `%LOCALAPPDATA%\PB-Radar\versions`.

**Обмеження:** Наявність номера в публічному реєстрі чи на сайті не доводить, що він чинний. OSM не є реєстром усіх компаній. Prozorro дає значно більше контактів закупівель, але серед них багато бюджетних замовників, що можуть не бути потенційними покупцями воріт або дверей; постачальники відбираються за CPV. Категорії й актуальність потребують перевірки менеджером, особливо виконроби та дизайнерські бюро. Дані не витягуються масово з Google Maps, Instagram або приватних акаунтів. Автоматичні дзвінки чи розсилки не виконуються. Інші джерела потребують окремої перевірки умов використання.

## Запуск для користувача

1. На вкладці [Releases](https://github.com/lyesm1th/pb-radar/releases) завантажити **PB-Radar-Setup.exe**. Пройти звичайне встановлення Windows — з'явиться ярлик **PB Radar** у меню «Пуск» і (за вибором) на робочому столі. `PB-Radar-Launcher.exe` залишається портативною альтернативою.
2. Відкрити програму з ярлика. Першого разу натиснути **Встановити** — лаунчер завантажить програму (але не великий архів OSM). Наступного разу з того самого ярлика можна натиснути **Оновити** або **Запустити**. Повторно качати інсталятор чи лаунчер при оновленні самої програми не потрібно.
3. **Для Prozorro OSM не потрібен.** Якщо бажаєш також шукати за картою, натисни **Завантажити / оновити OSM**. На 20.11.2026 Geofabrik має приблизно **885 МБ**, а резервний файл OSM France — приблизно **1,02 ГБ**; надалі розміри можуть змінюватися. Дані беруться зі спеціалізованих відкритих серверів OSM, а не з GitHub.
4. Дочекатися **першого індексування всієї України**. Воно може зайняти декілька хвилин або довше залежно від швидкості ноутбука; під час повторного пошуку з новими фільтрами індексація більше не проводиться.
5. Обрати категорії й області. **Запустити радар** — пошук по готовому OSM-індексу і сайтах. **Prozorro · контакти** — незалежний пошук публічних номерів закупівельників і підрядників. Можна використовувати обидва джерела; результати об'єднуються за номером.
6. У полі **ПОШУК В БАЗІ** знайти потрібні контакти за назвою, телефоном, областю, статусом тощо. **Експорт CSV** зберігає лише видимі записи з урахуванням фільтрів.
7. За потреби вибрати **«Тільки приватні»** й вимкнути **«Показувати Prozorro»**. Сім номерів однієї організації відкриваються стрілкою біля назви. Можна змінити ширину стовпців і вручну уточнити тип організації. Фільтри та ширини зберігаються після закриття програми.

Менеджер може позначати номери безпосередньо у таблиці: натискання на клітинку **☐** змінює статус на «Опрацьовано» і приховує номер із черги. Для деталізації обери рядок та статус («Не відповідає», «Потенційний партнер», «Не контактувати» тощо). Статуси записуються у локальну базу автоматично, а CSV-експорт/імпорт переносить їх між комп'ютерами.

**Де що зберігається після встановлення:**

| Призначення | Шлях Windows |
|---|---|
| Постійний лаунчер | `%LOCALAPPDATA%\Programs\PB Radar\PB-Radar-Launcher.exe` |
| Єдиний архів України | `%LOCALAPPDATA%\PB-Radar\cache\ukraine-latest.osm.pbf` |
| Локальний індекс | `%LOCALAPPDATA%\PB-Radar\cache\osm-index.sqlite3` |
| Номери і статуси | `%LOCALAPPDATA%\PB-Radar\contacts.sqlite3` |
| Версії застосунку | `%LOCALAPPDATA%\PB-Radar\versions\` |

**Для тих, хто вже користується PB Radar:** новий інсталятор підхопить наявні OSM і контакти з цих папок. Перевстановлення не призведе до повторного завантаження України. Видалення лаунчера через налаштування Windows свідомо залишає OSM і базу на диску, щоб вони не загубилися випадково.

Лаунчер може запустити вже встановлену версію навіть без доступу до GitHub. Власні контакти та статуси ніколи не завантажуються на GitHub.

## Розробка

Потрібен Python 3.12, для Windows-версії збірка відбувається саме на Windows runner.

```bash
python -m pip install -r requirements.txt pytest
python -m pytest -q
python run_app.py
python run_launcher.py
```

Якщо встановлений лаунчер не знаходить останній GitHub release, він показує помилку або дозволяє запустити вже встановлену версію. Репозиторій і релізи мають бути **публічними** для завантаження без GitHub-авторизації. Код не містить приватних номерів чи CRM-даних.

## Як випускати нову версію

GitHub Actions запускає тести, збирає `PB-Radar.exe` і `PB-Radar-Launcher.exe` через PyInstaller, а потім компілює установник через **Inno Setup**. Після push у `main`, якщо версія з `pbradar/__init__.py` ще не опублікована, Actions автоматично створює GitHub Release з `PB-Radar-App.zip`, `PB-Radar-Launcher.exe` та **`PB-Radar-Setup.exe`**. Для наступного релізу підвищити `__version__` і запушити зміни.

Якщо репозиторій приватний, GitHub Release доступний лише авторизованим користувачам. У цьому випадку лаунчер не може анонімно перевіряти оновлення й потрібен окремий публічний канал збірок (або зміна видимості репозиторію). Поки такого каналу немає, Windows-застосунок можна завантажити вручну з приватного Releases.

Стабільний лаунчер лишається на ПК; релізи замінюють лише виконуваний файл програми. Попередні версії залишаються в каталозі `versions` для відновлення.
