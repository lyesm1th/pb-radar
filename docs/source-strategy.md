# Джерела для наступного етапу PB Radar (23.11.2026)

## Пріоритет 1: ЄДР / ЄДРПОУ
Відновлені у 2026 році XML-набори Єдиного держреєстру юридичних осіб та ФОП використовувати для побудови **списку організацій**, а не як телефонний довідник. Селекція за КВЕД: 41.10, 41.20, 71.11, 71.12, 74.10, 43.29, 43.32. Перевіряти статус діяльності та код ЄДРПОУ, а телефони шукати окремо на публічних офіційних сайтах і в каталогах. Використовувати дозволені відкриті поля і дотримуватися вимог захисту персональних даних.
Джерело: https://nais.gov.ua/m/ediniy-derjavniy-reestr-yuridichnih-osib-fizichnih-osib-pidpriemtsiv-ta-gromadskih-formuvan

## Пріоритет 2: ЄДЕССБ
Дані будівельних проєктів, забудовників, проєктних і підрядних організацій для оцінки актуальності компаній. Зв'язувати з ЄДР за офіційним кодом, після чого шукати робочі телефони на сайтах самих фірм.
Джерело: https://e-construction.gov.ua/ua/vidkriti-dani

## Google Maps — не bulk-export
Google Maps Platform забороняє масово збирати та зберігати Maps Content у зовнішній локальній базі. Places API має SKU-квоти й платні операції. Доцільно давати **посилання для ручної перевірки** компаній, які виявлені з незалежних законних джерел, але не будувати на Maps вебскрапер масових телефонів.
Правила: https://developers.google.com/maps/documentation/places/web-service/policies
Тарифи: https://developers.google.com/maps/billing-and-pricing/pricing

## План інтеграції
1. Підготовка одного локального XML-індексу ЄДР, атомарна заміна при оновленні, без історії гігабайтних копій.
2. Окрема черга «компанії без телефонів» і збагачення через сайти за назва + ЄДРПОУ + місто.
3. Зберігати **всі** незалежні URL підтвердження в таблиці contact_sources (окрема майбутня міграція SQLite). У версії 0.5.2 підсвічується лише поточне збережене джерело кожного телефонного рядка.
4. Дедуплікація номерів, ЄДРПОУ, доменів. Не зливати одноіменні фірми без підтвердження.
5. Показувати окремо: записи ЄДР, організації з телефоном, унікальні номери, підтверджені незалежними джерелами, державні, невизначені, опрацьовані.
